# Expense Tracker with Budget Advice

A menu-driven command-line expense tracker written in Python.

## Features
- Add expenses with date, category, description and amount
- View all expenses and the total
- Set a monthly budget per category
- Get a summary showing which categories are over budget, close to the limit, or on track
- Input validation for numbers and menu choices

## How to run
expense_tracker (1).py

## Concepts used
Lists, dictionaries, functions, loops, conditionals, exception handling (try/except)

## Future improvements
- Save and load expenses from a CSV file
- Monthly reports and charts
- LLM-based spending advice
